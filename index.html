My Little Playground

Small things I've built and put online.

  • Town Drop A map quiz. A town name appears and you click its country before the clock runs out. Share a seed to play the same five towns as a friend. towndrop.stevan.co.rs → Source on GitHub
  • House Planner Draw a single-story floor plan in 2D, then walk through it in 3D and place furniture. realestate.stevan.co.rs → Source on GitHub
  • Game Collection My physical game collection, with cover art, filters, a game of the month, yearly awards and a map of where each game was bought. collection.stevan.co.rs → Source on GitHub
  • Desingerica Soundboard Thirty buttons, each one playing a line from Desingerica. desinger.stevan.co.rs → Source on GitHub
  • Gramophone A 3D horn gramophone that plays your MP3s. Wind the crank, watch the needle drop and listen through a crackly shellac filter. gramophone.stevan.co.rs → Source on GitHub
  • Caken A Streets of Rage–style beat 'em up you play by scrolling. Scroll down to fight through four levels, scroll up to rewind. caken.stevan.co.rs → Source on GitHub
  • Cookbook A family cookbook you flip through like a real book, with filters for ingredients, course, cuisine and cooking time. cookbook.stevan.co.rs → Source on GitHub
